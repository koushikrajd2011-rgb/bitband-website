FAQs

What is BitBand?

A YSWS run in Hack Club where you code artwork and we turn it into your own NFC wristband

Which tools can I use?

Only code: p5.js, Python, Canvas or SVG. No Figma or Procreate or AI, use the guide to learn

How long does it run?

About 3 weeks. Every 6 days a new themed round starts

How long should a project take?

Around 5 hours or less on average. This may change

What are BitDrops?

Secret, limited-time events that pop up on this site at random. Complete one to earn a holographic sticker sheet(its gonna be for one hour every 6 days so watchout)

What is a NFC chip?

NFC chips(currency) you can earn by making submissions. If you are wondering what an actual NFC chip is, it's a small device that can store and transmit data wirelessly
